# S3 Module

This module manages the manually-created S3 buckets in Connor's AWS account. The state bucket (`connor-ruff-terraform-state`) is intentionally excluded — it's managed in `bootstrap/`.

## Buckets

| Terraform resource | Bucket name | Purpose |
|---|---|---|
| `big_money_data` | `connors-big-money-data-bucket` | Primary data bucket for the GDrive → Snowflake pipeline. Lambda writes processed files here; Snowflake reads them via the `s3-read-access-for-aws-accounts` IAM role. |
| `misc_blob` | `connors-misc-blob-for-blobs` | General-purpose blob storage. eBird data lands in `ebird/`, Zeta Ball data in `zeta_ball/`, and the GDrive pipeline also writes here. |
| `python_packages` | `connors-python-packages` | Stores Lambda deployment packages (zip files) used as Lambda code sources. |

## Configuration

All three buckets share the same configuration:
- **Encryption**: AES256 server-side encryption with bucket key enabled
- **Public access**: fully blocked on all four settings
- **Versioning**: not enabled
- **Lifecycle rules**: none
- **Bucket policy**: none
